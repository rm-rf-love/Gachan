## 📥 Downloads & Installation

### Prerequisites
- Unlocked bootloader
- Custom recovery (OrangeFox/TWRP)
- Basic ADB & Fastboot knowledge

### Installation Guide
1. Download latest build from [Releases](https://github.com/rm-rf-love/android_device_xiaomi_fleur/releases)
2. Flash recovery via Fastboot
3. Wipe data/cache/dalvik
4. Flash LineageOS ROM
5. Flash GApps (optional)
6. Reboot and enjoy!
